# ⏱️ YouTube Playlist Calculator Pro

![Version](https://img.shields.io/badge/version-3.2-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge%20%7C%20Kiwi-lightgrey.svg)

> A sleek, premium browser extension that calculates the total and watched duration of any YouTube playlist. Stop guessing how much time a course or let's play will take — get instant, precise stats right on the page.

---

## ✨ Features

* **Glassmorphism UI:** A stunning, modern interface with background blur, dynamic shadows, and glowing hover effects that blend perfectly with YouTube's dark mode.
* **Smart Calculation:** Instantly calculates total playlist duration and tracks your exact watch progress based on YouTube's visual progress bars.
* **Custom Limits:** Want to know the time for just the first 50 videos? Enter a custom limit and get targeted stats.
* **3D Settings Panel:** A smooth `rotateY(180deg)` flip animation reveals the settings menu.
* **Multi-Language Support (i18n):** Instantly switch between English, Russian, Ukrainian, and German. Your choice is saved automatically via `chrome.storage`.
* **Zero Clutter:** No annoying popups. The UI is injected directly into the page and summoned elegantly via the right-click context menu.

## 🚀 How to Install (Unpacked Extension)

Since this extension is not yet in the Chrome Web Store, you can install it manually in a few seconds:

### Desktop (Chrome, Edge, Brave)
1. Clone this repository or download the `.zip` file and extract it.
2. Open your browser and navigate to the extensions page: `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder containing the extension files.
5. Done! Open any YouTube playlist and right-click on the page to calculate time.

### Mobile (Android)
1. Download **Kiwi Browser** or **Lemur Browser** from the Google Play Store.
2. Move the extension folder to your phone.
3. Open the browser, go to Extensions, enable Developer mode, and click **Load unpacked**.
4. To use it on YouTube, long-press on the page to open the context menu.
